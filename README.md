# One Line, One Laugh: Roast Your Fridge

make.fun bounty entry — a single-line roast of my fridge, written to get a laugh out of someone who has never met the appliance.

## Entry

> My fridge beeps if the door stays open ten seconds, but it let the milk expire three weeks ago without a word — apparently it only snitches on me, never on the dairy.

166 characters, one line. The joke turns on a specific, familiar detail (the door-open beeper) and pays off with a twist in the last few words: the fridge snitches on its owner but stays loyal to the dairy.

## How it works

`main.ts` (Node, no dependencies) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and validates it first: 1–200 characters, single line, not only whitespace.

Run it with:

```sh
node main.ts
```
